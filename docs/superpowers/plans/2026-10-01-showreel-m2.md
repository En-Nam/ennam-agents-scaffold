## Global Constraints (additions to M1's)
- **BT.709 (CTO overrule, M2 requirement):**
  - Encode converts the full-range BT.601 JPEG frames with `-vf scale=in_color_matrix=bt601:in_range=full:out_color_matrix=bt709:out_range=tv`.
  - Encode tags the stream `-colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv`.
  - `verify` asserts the banner shows `yuv420p(tv, bt709, …)` (all three tags bt709), else `E_VERIFY` naming `colorTags`.
- **No clipping:** every drawn text bbox (after transform) lies inside the 1920×1080 frame with a 48 px safe margin. This holds at the moment the beat is fully revealed (local progress 0.5 and the beat's last fully-on frame), for min / typical / max item counts at near-`maxChars` lengths.
- New archetypes are ports of spike A scenes (D11):
  - flow-graph ← s2 part B (install flow graph, path lights, converge);
  - layered-stack ← s3 slabs;
  - orbit-network ← s4 (brain-core, orbiting badges, packets);
  - card-carousel ← new, in the spike's glass-card language.
- They use canvas roles (`cache` for build-once sprites, which caused M0's root cause), `api.text`/`api.counter`/`api.unit` only, and no absolute times.
- Rendering stays sequential, 1 browser, GPU S=6 final / S=1 draft (M0 RULINGS).

### C14. Cue maps (Task 1 compiler; Tasks 2–5 consume)
For each `cueMaps[]` entry with `per: <slot>` and that slot bound to N items, the compiler emits N hits.
- Item i is named `<name>.<i>` (0-based), at `t = t0 + (from + (to−from)·i/max(1,N−1))·(t1−t0)`, snapped to GRID.
- If snapping collides (two hits within < 1 GRID in the same beat), the later hit is pushed by one GRID; if that passes `to`, compile fails `E_TIMELINE` naming the beat.
- Storyboard `cues[]` may override a mapped cue by full name (`"node.2"`).
- Archetypes read `cues["node.2"]` (local time). The score treats them as ordinary hits.

### C15. Arrangements (Task 1): `archetypes/arrangements.json`
`{"version":1,"arrangements":{"15":[…beats…],"30":[…],"45":[…],"60":[…]}}`
- Each beat is `{archetype, variant, weight, transitionOut}`.
- Beat counts sit within the duration budget (C4). The last beat is lockup-cta. The first is cold-open-command.
- 45/60 use ≥ 1 `chapter` card. Every archetype appears in the 60.
- Used by the test helper and later by the M3 agent as its default. A test validates each arrangement against archetypes.json (variants exist, budget ok).

### C16. Manifest bbox (Task 1 engine)
- `engine/text.mjs` records `{text, source, bbox:{x,y,w,h}}`, where bbox = the device-space bounds of the drawn text via `ctx.getTransform()` and measureText (actualBoundingBox*).
- `window.SHOWREEL.manifest()` returns them.
- New pure helper `lib/truth/safearea.mjs`: `export function offFrame(entries, {W:1920,H:1080,margin:48}) → [{text, source, bbox}]`.

### C17. Sheet + R5 (Task 7)
- `render/sheet.mjs` gains labels: beat id, archetype/variant, local t. 3 stills per beat (enter / hold / exit-start). 4 columns.
- New `tests/showreel/tools/r5-sheet.mjs` (dev tool, not shipped) renders spike A stills from `spikes/showreel-v0/index.html` (classic scripts, file URL, `renderAt(t, undefined, 6)`) and new-film stills, pairs them by beat type, and writes one labelled PNG (`spike A | M2`) per row:

  - orbit-network ↔ s4 t=10.8;
  - lockup-cta ↔ s5 t=13.4;
