# /showreel add-on — M1 (truth + determinism) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In a repo scaffolded with `<role> showreel`, `node .claude/showreel/cli.mjs` can run `preflight → facts → check → render --final → verify` on a storyboard and produce an exactly 30 s 1920x1080@60 H.264+AAC film. Every on-screen string must come from code-extracted facts or a fixed phrase library, and every frame must be byte-deterministic on the GPU path.

**Architecture:** This is a text-only toolkit installed by an opt-in add-on profile (`templates/showreel/`), with no scaffold-core change. There are three layers:
- **Node pure modules** (`lib/`): facts, truth, compile, score, preflight logic. They are dependency-free ESM and can be unit-tested hermetically.
- **Browser engine** (`engine/` + `archetypes/`): canvas renderer served by a local `node:http` server. It is a pure `draw(ctx, localT, params, resolved, cues)`, and it creates canvases only through a role factory.
- **Node render pipeline** (`render/`): puppeteer-core → JPEG q0.97 → ffmpeg → mux → verify.

Heavy deps are installed at first run with `npm ci` into `.claude/showreel/.tool/`.

**Tech Stack:** Node ≥ 22.12 (toolkit) · puppeteer-core 25.12.0 · ffmpeg-static 5.3.0 · @fontsource-variable/archivo 5.3.0 + @fontsource-variable/jetbrains-mono 5.3.0 (OFL) · vitest 4 (repo) · TypeScript only in `packages/cli/src` (registry wiring).

**Spec:** Serena `mem:decisions/showreel-addon-v1.16`. The **STATUS** block and the **M0 RULINGS** are binding and override older text. M1 = the "M1 truth + determinism" milestone. Spike reference: `spikes/showreel-v0/` (core.js, scenes/s1..s5, audio/make-score.mjs, analyze-score.mjs). Rulings: `mem:comms/active/cto-small-eye-to-dev-big-head-showreel` ("CTO RULING on M0").

## Global Constraints

- Toolkit runtime: **Node >= 22.12**. `cli.mjs` must parse on Node 18+ and refuse older Node with an actionable message *before* any dynamic import. Scaffold CLI stays Node >= 20.
- Exact pins in the deps manifest: `puppeteer-core 25.12.0`, `ffmpeg-static 5.3.0`, `@fontsource-variable/archivo 5.3.0`, `@fontsource-variable/jetbrains-mono 5.3.0`. A lockfile ships with them and installs run via `npm ci`.
- **No core change:** do NOT edit `templates/_shared/**`, the CLAUDE.md block or its golden, `packages/cli/src/{execute,render,conflict,enumerate}.ts`. Allowed: `profiles.ts`, `list.ts`, `ux.ts`, `classify.ts` (rule additions only), new files. If something cannot work without a core change: STOP and escalate to @cto-small-eye.
- Nothing binary in `templates/` (the installer is UTF-8 text only). No `node_modules`/`.tool` under `templates/` (tsup copies all templates into the npm package).
- Render policy (M0 RULINGS):
  - `--final` = GPU, S=6, 60 fps, 1 browser, crf 18 (14 with `--master`).
  - `--draft` = S=1, 30 fps.
  - GPU-less (renderer string contains `SwiftShader`) → `--final` uses S=1 @60 fps and prints the exact notice `no GPU detected — motion blur reduced (S=1)`.
  - No parallelism. Capture = JPEG q0.97.
- Determinism (D9 amended):
  - Draw is a pure function of time.
  - Seeded RNG only. **No `Math.random`, no `Date.now`, no `performance.now`** in engine/archetypes/score/compile.
  - No frame-carried state.
  - Canvases are created ONLY via `engine/canvas.mjs` `makeCanvas(role, w, h)`:
    - `stage`/`frame` → GPU (default context);
    - `cache` → `getContext('2d', {willReadFrequently: true})`.
  - A test bans `createElement('canvas')`, `new OffscreenCanvas`, `.getContext(` outside `engine/canvas.mjs`.
- Truth (D8 / Rule 13):
  - The LLM storyboard contains enums, numbers, factIds and phraseIds only. Free text anywhere fails validation.
  - The resolver never uses echoed strings.
  - All drawn text goes through the engine text API, which records a manifest; the manifest must be ⊆ the resolved set.
- Timeline (D10): `build/timeline.json` is the only time source for picture and audio. No literal absolute seconds in `engine/`, `archetypes/`, `lib/score/` (test-enforced).
- Duration (D13):
  - video = exactly N×fps frames;
  - audio = N×48000 samples ±1024 after decode;
  - mux without `-shortest`.
- Output: compact machine-readable JSON on stdout. One line, `{"ok":bool,"cmd":"…",…}`. Errors are `{"ok":false,"cmd":"…","error":{"code":"…","message":"…","fix":"…"}}` with exit code 1.
- Host repo paths:
  - toolkit `.claude/showreel/`;
  - work dir `showreel/`: `facts.json`, `storyboard.json`, `build/…`, `<slug>-<N>s.mp4`;
  - preflight writes `showreel/.gitignore` (`build/`, `*.mp4`) and `.claude/showreel/.gitignore` (`.tool/`) if absent.
- Tests: vitest files under `tests/showreel/**`. Browser tests are gated by `SHOWREEL_E2E=1`; skips are reported.
- Repo dev tool dir: `.showreel-dev/.tool` (gitignored). Tests and agents find deps via env `SHOWREEL_TOOL_DIR`.

## Review Focus

1. **Repo with non-ASCII app name or tagline** (Vietnamese, emoji). Expect no tofu: glyph coverage fails loudly naming the char and slot, or the char renders. Owner: Task 6 (`engine-glyphs` test).
2. **Fact text far longer than the slot** (a 90-char command). Expect shrink to min size, then a `check` failure naming beat+slot. Never clipped silently. Owner: Task 6 (`textfit` test).
3. **Storyboard whose weights/beat count violate the duration budget, or last beat ≠ lockup-cta.** Expect a validation error naming the rule. Owner: Task 3 (`validate` test).
4. **Re-running `facts` on an unchanged repo after a commit.** Expect `facts.json` byte-identical (B5). Owner: Task 2 (`facts-stable` test).
5. **Host on Windows with Edge only, or no browser, or no ffmpeg reachable.** Expect an actionable preflight error with the env var to set. Owner: Task 7 (AC8 tests).

### C3. facts.json (Task 2 produces; schema Task 1)
```json
{ "version": 1,
  "minimumGate": { "passed": true, "missing": [] },
  "brand": { "name": "Acme Shop", "palette": "violet", "wordmark": "f.app.name.1" },
  "facts": [ { "id": "f.route.3", "kind": "route", "value": "/checkout", "display": "/checkout",
               "unit": null, "source": { "file": "app/checkout/page.tsx", "locator": "path", "extractor": "next-app-routes", "rule": "app/**/page.(tsx|jsx|ts|js) → route path" },
               "collection": "routes", "order": 3, "hash": "sha256:…16 hex" } ] }
```
- Kinds (closed enum): `app.name`, `app.tagline`, `feature`, `stack.item`, `route`, `command`, `count`, `problem`.
- `count` facts: `value` is an integer, `display` is the formatted integer (`"42"`), `unit` is a lowercase plural noun from code (`"routes"`).
- Ids are `f.<kind>.<n>`, n 1-based in extraction order, and stable for the same repo state.
- `hash` = sha256 of `kind|value|source.file|source.locator`, first 16 hex.
- `palette` is an enum: `violet` | `cyan` | `amber` | `mint`. Default `violet`.
- Commit-dependent data (HEAD sha, generatedAt, raw commit counts) goes ONLY to `build/facts.meta.json`.

### C4. storyboard.json (agent writes in M3; tests write fixtures; schema Task 1)
```json
{ "version": 1, "durationS": 30, "seed": 7, "palette": "violet",
  "beats": [ { "id": "b1", "archetype": "cold-open-command", "variant": "terminal", "weight": 1.0,
               "bindings": { "command": "f.command.1" }, "phrases": { "caption": "p.open.2" },
               "transitionOut": "zoom-through",
               "cues": [ { "name": "enter", "at": 0.75, "kind": "boom", "amp": 1.0 } ] } ] }
```
- `durationS` ∈ {15,30,45,60}. Beat count: 15→4–5, 30→7–8, 45→10–11, 60→13–14.
- `weight` 0.5–3. `transitionOut` ∈ {`cut`,`zoom-through`}; the last beat's is ignored.
- Last beat archetype MUST be `lockup-cta`. The beat `id` pattern is `^b[0-9]{1,2}$`.
- `cues[].kind` ∈ {`boom`,`snap`,`sweep`,`thud`,`lock`,`ignite`,`pop`,`slam`}; `at` 0..1; `amp` 0..1.
- No string field accepts free text: all strings are enums or match id patterns.

### C6. phrases.json (Task 3)
`{"version":1,"phrases":[{"id":"p.<tag>.<n>","tags":["open"],"text":"…"}]}`. These are generic, repo-agnostic and always true (e.g. `p.cta.1` "Get started", `p.open.1` "One command."). At least 3 phrases per tag across tags `open`, `lead`, `metrics`, `cta`. ASCII only.

### C7. resolved.json (Task 3 produces; Task 6 consumes)
```json
{ "version": 1, "beats": { "b1": { "archetype": "cold-open-command", "variant": "terminal",
   "slots": { "command": { "source": "fact", "items": [ { "id": "f.command.1", "text": "npm run dev", "number": null, "unit": null } ], "fitSizePx": null },
              "caption": { "source": "phrase", "items": [ { "id": "p.open.1", "text": "One command.", "number": null, "unit": null } ], "fitSizePx": null } } } },
  "allowed": [ "npm run dev", "One command." ] }
```
- `text` comes ONLY from `fact.display` / `phrase.text`. `number` = `fact.value` for `count`. `unit` = `fact.unit`.
- `allowed` = sorted unique texts plus units.
- `fitSizePx` is filled by `check` (Task 8) from the in-browser text fit.

### C8. timeline.json (Task 4 produces; Tasks 5/6/8 consume)
```json
{ "version": 1, "fps": 60, "durationS": 30, "frames": 1800, "seed": 7, "palette": "violet",
  "beats": [ { "id": "b1", "archetype": "cold-open-command", "variant": "terminal", "t0": 0, "t1": 3.5, "overlapIn": 0, "overlapOut": 0.375, "transitionOut": "zoom-through" } ],
  "hits": [ { "t": 2.5, "kind": "boom", "amp": 1, "beatId": "b1", "cue": "enter" } ],
  "typing": [ { "beatId": "b1", "t0": 0.45, "interval": 0.052, "chars": 11, "enterAt": 2.5 } ],
  "sections": [ { "name": "intro", "t0": 0, "t1": 3.5 } ],
  "music": { "bpm": 120, "key": "F#m" } }
```
- Beat boundaries and hit `t` sit on the 1/16-note grid (0.125 s at 120 bpm), NOT necessarily on the frame grid: draw is continuous in t, and a hit lands ≤ ½ frame from a frame. A zoom-through overlap (3 GRID) spans boundary −2 GRID … +1 GRID. (Amended after Task 4: "1/16 AND 1/fps" forced a 0.25 s grid.)
- `beats[0].t0 = 0`; `beats[last].t1 = durationS`.
- `overlapOut[i] = overlapIn[i+1]`: 0.375 for zoom-through, 0 for cut.
- `sections[].name` ∈ {`intro`,`build`,`peak`,`outro`}: roles open → intro, close → outro; body beats are split build/peak at the 60% mark.
- Hits are sorted by t.

### C9. Archetype module (Task 6) — browser ESM, `archetypes/<id>.mjs`
```js
export default {
  id: 'metrics-counter-lock',
  layout(resolved, variant, api) { /* pure; run once per beat; returns plain object */ },
  draw(ctx, localT, params, resolved, cues) { /* params = {dur, variant, seed, W, H, layout, palette, api, beatId} ; cues = {name: localT} */ },
};
```
- `api` = engine helpers (math/easing/rng/hash/noise/palette/`text`/`counter`/`glass`/`glow`/`makeCanvas`). Archetypes NEVER call `ctx.fillText`/`strokeText` directly.
- The transition `archetypes/transitions/zoom-through.mjs` exports `{ id, apply(ctx, k, drawOut, drawIn, api) }`, with `k` = 0..1 over the overlap.

## Task 4: Timeline compiler (`lib/compile/**`)
**Files:** Create `lib/compile/timeline.mjs`: `export function compileTimeline(storyboard, resolved, archetypes, {fps}) → timelineJson (C8)`. Test: `tests/showreel/compile.test.ts`

Rules:
- `GRID = 60 / bpm / 4` (bpm 120 → 0.125 s). Beat raw length = `weight / Σweights × durationS`.
- Boundaries are cumulative sums, each rounded to the nearest GRID multiple (ties → down). No beat may end shorter than `max(1.0 s, minWeight-scaled)`; if rounding violates this, steal from the longest neighbour.
- `overlap` = 0.375 for zoom-through (exactly 3 GRID). The overlap is centred on the boundary: `beats[i].t1 += overlap/2`, `beats[i+1].t0 -= overlap/2`. Clamp at the 0 and durationS ends.
- Hits: for each beat, default cues merged with storyboard cues (storyboard wins by name); `t = t0 + at × (t1 − t0)` snapped to the GRID, then to the frame grid.
- Typing (for an archetype with `typing` slot):
  - `t0 = beat.t0 + 0.45`, `chars = text.length`, `interval = min(0.052, (enterAt − t0 − 0.2)/chars)`;
  - `enterAt` = the `enter` hit t.
  - The constants 0.45/0.052/0.2 live ONLY in compile.
- Sections per C8. `music = {bpm:120, key:'F#m'}`. `frames = durationS × fps`.
