# OKR authoring playbook

OKRs turn a strategy into something you can measure. A good set has one objective and a handful of key results that are impossible to fake. Use this skill any time you draft OKRs or review them before they're committed.

## Structure

- **One objective.** Qualitative, inspiring, time-bound — what matters most this period. If you need two objectives, you probably haven't prioritized.
- **3-5 key results.** Each is a measurable outcome with a baseline and a target. Format: `<metric>: <baseline> → <target> (source: <source>)`.

Fewer, sharper KRs beat a long list. Five is a ceiling, not a goal.

## Every KR has a baseline and a target from a real source

- A KR without a baseline is a wish — you can't tell if `→ 20%` is a stretch or a step back without knowing where you started.
- Both the baseline and the target come from a named source (dashboard, finance export, analytics query). Never invent either number or recall it from memory. If it's not in hand, write `[SOURCE TBD]` and surface it (Rule 13).

## No vanity metrics

A key result must measure an **outcome**, not activity.

| Vanity (reject) | Outcome (use) |
|---|---|
| Page views, impressions | Activation rate, qualified pipeline |
| Headcount hired | Revenue per employee, delivery throughput |
| Features shipped | Adoption of shipped features, retention |
| Hours logged, meetings held | Cycle time, customer outcomes |

Test each KR: *if this number goes up but the business doesn't get healthier, it's vanity.* Cut it.

## Measurable, not aspirational-only

- A KR must have an objective yes/no or a number at period end. "Improve morale" is not a KR; "eNPS: 12 → 25 (source: Q2 engagement survey)" is.
- Avoid KRs whose only judge is opinion. If it can't fail on the data, it can't pass on the data either.

## Review checklist (before OKRs are committed)

- Exactly one objective, qualitative and time-bound.
- 3-5 key results, no more.
- Every KR has a baseline and a target, each from a named source (Rule 13).
- No vanity metrics — every KR measures an outcome, not activity.
- Every KR is objectively measurable at period end.
- Any missing number is a visible `[SOURCE TBD]`, not a guess.
