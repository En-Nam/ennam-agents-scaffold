description: Draft one objective plus 3-5 measurable key results (no vanity metrics), saved to okr/<period>.md.
---

Usage: `/ceo-okr <period>`

Steps:
1. If the strategic priority for the period or the current baselines are missing, ask the user before drafting.
2. Read prior OKRs in `okr/` to match tone and to check continuity with last period's results.
3. Write **one** objective — a qualitative, inspiring, time-bound statement of what matters most this period.
4. Write **3-5 key results**, each measurable with a baseline and a target from a real source. Format: `<metric>: <baseline> → <target> (source: <source>)`.
5. Reject vanity metrics — key results measure outcomes (revenue, retention, margin, cycle time), not activity theatre (page views, raw headcount, hours logged).
6. Mark any missing baseline or target as `[SOURCE TBD]` and surface it — never invent a number (Rule 13).
7. Save to `okr/<period>.md`.
8. Flag any KR that isn't objectively measurable or that reads as a vanity metric (Rule 12).
