### Financial Close Workflow (Record → Reconcile → Report)

The month/quarter/year-end close. Every figure is transcribed from and cites a source document — no number is recalled from memory or "plugged" to make a total balance (Rule 13). Account classification and estimates are human judgment; the model drafts and extracts but does not decide or do the arithmetic (Rule 5).

#### Phase 1 — Cut-off & Gather
Draw a hard line at the period-end date and collect every source document — invoices, bank statements, receipts, sub-ledgers, payroll — before touching the books. Anything not yet received is marked `?`, never assumed to be zero. Source docs carry bank/salary/vendor data — handle per POLICY, take only what the close needs.

#### Phase 2 — Record & Classify
Post each transaction to the correct account and, on every line, write down which document it came from — like filing each receipt in a clearly labelled folder. Debit/credit amounts are copied from the source, never typed from memory (Rule 13). Which account/tax code a transaction belongs to is a human judgment call.

#### Phase 3 — Reconcile to Source
Match the books against independent proof — bank statement, AP/AR sub-ledger, supplier/customer statements, intercompany, fixed-asset register — until every balance agrees. Each reconciling difference is itemised with a cause; an unexplained difference blocks the close and is surfaced, never silently plugged. **This is the role's built-in Rule-13 guardrail — never skipped.**

#### Phase 4 — Review & Adjust
Step back and ask "does this actually make sense?" — run variance analysis against prior periods and budget, chase odd swings, post correcting or accrual entries. Accruals, provisions, estimates, and materiality calls are professional judgment (Rule 5); every variance above the materiality threshold is surfaced and explained (Rule 12).

#### Phase 5 — Approve & Lock
Get the controller's or CFO's explicit sign-off before any number leaves the building — statutory statements, tax, filings, the board pack — then lock the period. An outward-facing or irreversible action stops for a named, recorded human approval (POLICY approval gate). Statutory/tax obligations are a consult-a-human/accountant matter, not a guarantee.

#### Phase 6 — Report & Archive
Produce the final statements/management pack and file the complete paper trail — which document, which reconciliation, who approved, on what date — so an auditor (or next month's you) can retrace every number back to its source (audit-to-Serena; reproducibility).

### Definition of Done
The period is reconciled and locked: every figure traces to a source, every reconciling difference is explained (none plugged), variances above materiality are resolved, the named approver signed off (recorded), and another accountant could reproduce every reported number from the cited sources. A close with an unexplained difference, an untraceable figure, or no recorded sign-off is NOT done — say so plainly (Rule 12). This is a starting-point checklist, not accounting/tax/legal compliance.
