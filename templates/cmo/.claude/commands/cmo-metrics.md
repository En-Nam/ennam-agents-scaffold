---
description: Draft a growth/marketing metrics report for a period, saved to metrics/<period>.md.
---

Usage: `/cmo-metrics <period>`

Steps:
1. If the period's metrics or the dashboards/exports to pull them from are missing, ask the user for them or the source before drafting.
2. Read prior reports in `metrics/` to match tone and to keep the running trend line consistent.
3. Draft the report with sections: Highlights, Lowlights, Funnel metrics (acquisition → activation → retention → revenue), and Channel performance.
4. Every figure cites its source — format each as `<metric>: <value> (source: <source>)`. Never recall a number from memory; if it isn't in hand, write `[SOURCE TBD]` and surface it (Rule 13).
5. Prefer outcome metrics (activation, retention, qualified pipeline, CAC/LTV) over vanity metrics (impressions, raw follower counts).
6. Save to `metrics/<period>.md`.
7. Surface every unsourced figure loudly — a metrics report with a visible `[SOURCE TBD]` is honest; one with an invented number is not (Rule 12, Rule 13).
