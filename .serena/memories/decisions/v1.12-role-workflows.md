## Context
After round 1 filed #22-#30, CTO Danny: the plan routes ceo/ciso/hr to the GENERIC `doc-first-signoff`
— not a real accountant/CFO/CEO workflow. Asked to develop position-specific workflows. Key CTO insight:
a finance workflow whose Validate/Reconcile phase MANDATES "every number traces to a source, no
LLM-recalled figures" IS the Rule-13 guardrail → authoring finance workflows LOWERS risk. Ran a focused
Workflow (8 agents: 6 role designers + 1 holistic reviewer + 1 project-owner). Main session filed issues.
NOTE: proceeded on 2 default scope calls (AskUserQuestion tool errored, user said "continue"): breadth =
Exec+Finance+HR cluster; finance = profile+workflow together — but the CRITIQUE overrode the second
(finance profile DEFERRED, workflow-only ships now). Surfaced to CTO.

## Decision — 4 role-FAMILY presets (critique cut 6 → 4, Rule 2 anti-proliferation)
Each preset = ONE markdown phase-list under `templates/_shared/workflow/<id>.md`, plugged into the #23
`{{{workflowSection}}}` slot, selected via `ProfileDef.recommendedWorkflow`. Every phase carries a
one-line PLAIN-LANGUAGE explanation for non-tech users (explicit CTO requirement).
1. **people-lifecycle** → hr (Frame→Gather need-to-know→Draft→Fairness/EEOC check→Human-decision→Sign-off/retention). Ships END-TO-END now (hr exists; needs only #23).
2. **exec-decision** → ceo (Frame→Evidence→Options-no-rec[Rule7]→Decide[Rule5]→Deck/OKR→Validate-figures[Rule13, PORTED from cut finance-plan-review]→Sign-off). Also serves cfo board-planning + coo one-off.
3. **security-incident** → ciso (NIST: Intake/Declare→Scope-from-evidence[Rule13]→Contain[gate]→Notify[gate]→Post-mortem). ciso also gains autoPolicy:true.
4. **finance-close** → accounting/kế toán (R2R: Cut-off&Gather→Record&Classify→Reconcile-to-Source[Rule13 keystone]→Review&Adjust→Approve&Lock[POLICY gate]→Report&Archive). Ships WORKFLOW-ONLY; no profile recommends it yet.
